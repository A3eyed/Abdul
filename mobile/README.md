# Abdul Mobile (iOS + Android)

Native-class apps so Abdul lives on your personal phone.

## Phased delivery

### Phase 1 — Phone as interface (available path now)
- **WhatsApp** (primary): text Abdul from the app you already use
- Optional later: iMessage (needs Mac), Telegram

No App Store wait. Brain runs on VPS/desktop host; phone is the remote control.

### Phase 2 — Cross-platform app
- **Flutter** (preferred) or React Native
- Features: chat, push notifications, quick actions, settings, permission controls
- Talks to the same Abdul API as desktop

### Phase 3 — Deeper device integration
- Share sheet targets
- Notification summaries (where OS allows)
- Limited automation (Android more flexible; iOS more restricted)
- Optional sensors only with explicit opt-in

## Privacy

- No silent full-phone surveillance
- You choose what the app may read or send
- Profile data stays on your hosts / encrypted storage you control
